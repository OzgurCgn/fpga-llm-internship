# FPGA-Oriented LLM Inference: Reproducible Experiments

This repository contains a verifiable, FPGA-oriented internship engineering project. Experiments are explicitly separated by verification level: CPU tests, RTL simulation, open-source synthesis, and optional AMD Vitis HLS/Vivado.

**CI results do not constitute proof of physical FPGA execution or AMD vendor-tool synthesis.**

The project explores MatVec/MatMul, RMSNorm, Softmax, RoPE, ready/valid AXI4-Stream, and a workflow for documenting reproducible test evidence. Details and setup instructions will be added with the source commit.
